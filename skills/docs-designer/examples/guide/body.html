Before you start

You need Python 3 and Google Chrome or Chromium. Nothing else is installed.

Describe the document

Create doc.json next to your body file. Pick a kind and, for Bulgarian, set the language.

{
  "kind": "guide",
  "lang": "en",
  "title": "Writing a document",
  "body": "body.html"
}

Write the body

  1. Start every section with an <h2>; sections are numbered automatically.

  2. Use callouts for decisions and warnings, and a table for comparisons.

  3. Keep code lines short so they don't wrap.

Print it

python3 scripts/render.py doc.json --out guide.pdf

The date is always the moment you print. Re-print to update it.
