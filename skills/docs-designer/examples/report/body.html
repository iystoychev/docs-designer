The design must look the same in every document, work offline and need nothing beyond what is already on the machine.

Context

Documents are written as a small HTML body and a JSON description. A renderer combines them with the shared template and stylesheet and prints an A4 PDF.

Rendering options

WeasyPrintNot installed on this machine
Headless ChromeChosen: already installed, supports @page margin boxes

The design lives in code. The template, stylesheet and renderer own every visual decision, so documents cannot drift apart.

Chrome must be installed. If it is somewhere unusual, set CHROME_PATH before rendering.

How a document is printed

python3 scripts/render.py doc.json --out docs/report.pdf

Make sure that the name of the author is included and the date that the document is created.
