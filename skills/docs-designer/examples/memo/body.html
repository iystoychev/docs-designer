Why

Documents are now written in Bulgarian as well as English. The previous headline font, Archivo, has no Cyrillic letters, so Bulgarian headings fell back to a system font.

Roboto Flex covers Latin and Cyrillic and has the same adjustable width, so condensed titles and wide labels keep working.

What changes

  • Headings, labels, tables and the front page use Roboto Flex.
  • Body text stays in Source Serif 4 and code in JetBrains Mono; both already support Cyrillic.
  • Set "lang": "bg" in a document to get Bulgarian labels and dates.
